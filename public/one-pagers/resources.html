Resources

Originally it was supposed to be a specifically website-building resources list, but I've decided that keeping there other resources I find helpful would be even more handy!

/ last upd. 1 nov 2026

Website set up + frontend

Overall html/css/js guides

  • Documentations and overall syntax/elements/etc-explaining sites. Extremely helpful!
    • w3schools
    • codecademy
    • MDN Web Docs
    • freeCodeCamp
    • htmldog
    • Interneting is hard – explains the very basics of html and css specifically.
  • General beginner webmaster guides
    • petrapixel – extremely helpful and beginner-friendly tutorials. Her github guide was genuinely a lifesaver for me, just saying.
    • Tyoma's Beginner Website-Making Resources
  • Grid and Flexbox layout guides/cheatsheets

Cool layouts/snippets/etc

  • W3Schools's snippets
  • stupied's templates and snippets!
  • crotovane's neat gallery template
  • e0nbreak's masterlist of a Large amount of templates you can use!
  • Grid layout generator
  • favicon generator (a pretty little site icon, i have one with a twin peaks bird for example) + how to set one
  • solaria's tutorials

Other helpful tools

  • deadlinkchecker – Extremely helpful resource for finding all the broken links on your website!
  • WAVE Web Accessibility Evaluation Tools – Helps to check pages accessibility.
  • Ritual.sh's button generator – A website button maker I wish I'd discovered earlier

Art-related

References

  • Human
    • pose.aphrite – Choose any pose and angle of a 3d model and get a bunch of photo refs of it! Note: if you're as confused as I was when I first interacted with the site, you need to click a search icon at the top left corner when you want to see refs. Yeah. The image quality is pretty much eh for now, but still quite useful.
    • jookpubstock – A plenty of great photo references (feminine body type specifically)
    • vishopper – Pose references with quite a lot of filters to apply (including age group, light/shadow type/direction, pose type, number of people, etc)
    • scry.studio – Refs database from art museums, quite neat!
  • Animals
    • x6ud's Animal Photo References – Provides a skull 3d model and searches for animal photos from more or less same angle
    • 3d animal skulls

Figure/gesture drawing timed sessions

  • New Masters Academy's Timed Nude Figure Poses (1), Timed Nude Figure Poses (2), Timed Non-nude Figure Poses and Figure drawing sessions with instructors
  • quickposes – has challenges (pre-established pose groups) or random timed poses (or faces/hands/animals/landscapes if you'd like to choose them for practice)
  • sketchdaily – pretty much similar to quickposes, but provides an opportunity to have a randomized timed sessions, using your own refs
  • Line-of-action – similar to above mentioned quickposes and sketchdaily as well, but additionally has primitive figure drawing timed classes, which is neat!

Textures

  • Transparent textures – some cool free textures!

Worldbuilding

Character hosting sites

  • Toyhouse – The most obvious one, I believe, and the one I love dearly. Gives you lots of customization options and a large amount of free templates, made by other users. The main cons I'm aware of are:
    • a) it has a strict policy against CBCs (fandom character-based characters) that have little to no changes in their name and story/biography = The site administration would not be okay with, say, Albert Wesker's fursona that is basically Wesker but a dog/cat/etc, but a separate character that was inspired with Wesker's design, personality and story (and has another name, if I understand that part of the rules right) would be alright.
    • b) it's still in an invite-only beta, which means you need to have an invite code to create an account here. I have lots of spare ones though I'd be happy to give to anyone who needs one, so feel free to dm me on any of my active socials, or, that would be even more convenient, scrimtas@gmail.com (just not via comments or guestbook so no one can snatch your code before you'll have a chance to use it!)
  • CharacterHub – Doesn't require any html or css knowledge from its user and works with pre-established layout mostly, although it has some cool snippets to choose from. I didn't vibe with it much personally (too clattered and social media-like for my old soul/hj) but the project is cool nevertheless and who knows, maybe you'd like it better!
  • Keepsake – A very new player on a scene, which I'm still need to test properly! Based on my first impression, pretty much reminds of toyhouse (and is also invite-only) but a) 18+ b) chill about CBCs and fandom character aus c) obviously has a smaller community, because, well, its both invite-only and new
